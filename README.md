# 🌱 Plant Disease Prediction Using Deep Learning

A Deep Learning-based image classification project that predicts plant diseases from leaf images. The project uses a Convolutional Neural Network (CNN) approach to classify plant leaf images into different disease categories.

## 📌 Project Overview

Plant diseases can significantly affect agricultural productivity and crop quality. Early identification of diseases can help farmers take appropriate preventive and treatment measures.

This project applies Deep Learning and image classification techniques to identify plant diseases from images of plant leaves.

The model is trained using plant leaf images and can be used to predict the disease category of a new leaf image.

## 🎯 Objectives

- Develop a Deep Learning model for plant disease classification.
- Process and prepare plant leaf images for model training.
- Train an image classification model using Deep Learning.
- Evaluate the model's classification performance.
- Predict plant diseases from new leaf images.
- Demonstrate the practical application of AI in agriculture.
